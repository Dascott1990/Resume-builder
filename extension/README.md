# Noqeev Job Saver (Chrome extension)

Saves a job posting straight into your Noqeev Job Tracker as a "Saved" application, from whatever page you're looking at.

**Not published to the Chrome Web Store.** That's a separate submission (developer account, review, listing assets) that wasn't part of this build. For now it only runs as an unpacked/sideloaded extension.

## Install (unpacked, for yourself or testers)

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this `extension/` folder.
4. Pin the extension (puzzle-piece icon → pin) so it's easy to reach.

## Connect your account

1. On noqeev.com, go to **Profile → Browser extension → Create a token**.
2. Copy the token (starts with `npat_`) — it's only shown once.
3. Click the extension icon, choose **Connect account**, paste the token.

## Use it

Open a job posting (LinkedIn, Indeed, a company careers page, anywhere), click the extension icon. Company/role/description are pre-filled from the page where possible — always editable before saving. Click **Save to Job Tracker**.

Revoke access any time from the same Profile screen; the extension stops working immediately.
